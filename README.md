# Kisan Setu

### Smart Agricultural Procurement & Logistics Platform

Kisan Setu is a smart platform connecting **farmers and buyers** to make agricultural procurement faster, transparent, and predictable.

## Key Features

### Farmer
- Smart slot booking
- Live queue tracking
- Weather-based travel alerts
- QR-based check-in
- Payment tracking
- Digital grievance management

### Buyer / Mandi
- View farmer bookings
- QR check-in and token management
- Weighing and grading
- Price and bill management
- Transaction and payment updates
- Procurement analytics

## Technology Stack

- **Frontend:** React Native, React.js
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL
- **Real-time:** Firebase Realtime Database
- **Weather:** OpenWeatherMap API
- **Automation:** Haversine Formula, Moving Average, Rule-based Analytics
